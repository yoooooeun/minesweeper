## 게임 소개

<!-- 어떤 게임인가요? 규칙을 간단히 설명해주세요. -->
고전적인 지뢰찾기(Minesweeper) 게임입니다. 격자 내에 숨겨진 지뢰를 피해 모든 안전한 칸을 찾아내는 것이 목표입니다.

기본 규칙: 9x9 격자에 10개의 지뢰가 숨겨져 있습니다.

좌클릭: 칸을 엽니다. 지뢰가 있으면 게임 오버, 빈칸이면 주변의 지뢰 개수를 알려줍니다.

우클릭: 지뢰가 있다고 예상되는 곳에 깃발을 꽂습니다.

안전장치: 유저의 불쾌한 경험을 막기 위해 첫 클릭은 무조건 지뢰가 없도록(안전하게) 설정되었습니다.

## 어떻게 만들었나요
AI 에이전트를 활용한 구조화된 개발 프로세스를 거쳐 완성했습니다.

PRD 작성: 먼저 게임의 핵심 규칙, 승패 조건, 화면 요소 등을 명확하게 정의하는 기획 문서(PRD)를 작성했습니다.

Plan 확인 및 보완: 에이전트가 코드를 작성하기 전, PRD를 바탕으로 세운 개발 계획(Plan)을 검토하고 누락된 로직(예: 첫 클릭 안전 보장)을 보완했습니다.

Agent 구현: 확정된 계획을 바탕으로 에이전트가 HTML/CSS/JavaScript 코드를 생성하도록 지시하였고, 버그를 수정하며 완성했습니다.

## freeform 버전과 비교했을 때
freeform 브랜치 (프롬프트 자유 작성): 단순히 "지뢰찾기 게임 만들어줘"라고 요청했을 때는 UI가 투박하거나, 첫 클릭에 지뢰가 터지는 등 세부적인 게임 밸런스나 예외 처리가 부족했습니다. 코드의 구조도 예측하기 어려웠습니다.

prd 브랜치 (PRD 기반 작성): 명확한 요구사항 문서(PRD)를 먼저 제공하고 계획을 검토한 뒤 코드를 짜게 하니, 버그가 훨씬 적고 요구한 규칙(타이머, 남은 지뢰 수, 첫 클릭 안전 규칙 등)이 정확하게 반영되었습니다.

선택 이유: 유지보수가 쉽고 기획 의도가 100% 반영된 안정적인 결과물이기 때문에 prd 버전을 최종으로 선택했습니다.

기본적인 지뢰찾기 기능 외에 다음과 같은 요소를 추가/수정했습니다.

UI/UX 개선: 단순한 텍스트 대신 이모지(💣, 🚩, 💥)를 사용하여 시각적 재미를 더했습니다.
