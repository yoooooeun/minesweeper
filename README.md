# 💣 지뢰찾기

> 이 README는 게임을 완성한 뒤, 배포 직전 단계에서 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

안전한 칸을 열고 주변 지뢰 수를 단서로 모든 안전 칸을 찾아내는 지뢰찾기 게임입니다. 지뢰가 있는 칸은 우클릭으로 표시하고, 모든 안전 칸을 열면 승리합니다.

초급(9×9, 지뢰 10개), 중급(16×16, 지뢰 40개), 고급(16×30, 지뢰 99개) 난이도를 제공합니다. 첫 클릭은 안전하며, 빈 칸 주변은 자동으로 열립니다.

## 어떻게 만들었나요

PRD의 요구사항을 구현 계획으로 확인한 뒤, Vanilla JavaScript와 HTML/CSS로 게임 동작과 화면을 구현했습니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 실행할 수 있습니다. 별도의 빌드나 패키지 설치가 필요하지 않습니다.

## 커스터마이징한 부분

- 난이도 선택과 작은 화면을 위한 가로 스크롤 게임판
- 켜고 끌 수 있는 효과음 (기본값: 끔)
- 브라우저에 저장되는 난이도별 최고 기록
- 첫 클릭 안전, 빈 칸 연쇄 공개, 승리·패배 상태 표시
